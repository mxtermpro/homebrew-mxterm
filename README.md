Install **[MXterm Pro](https://mxterm.net)** with Homebrew on macOS. MXterm Pro is a desktop terminal for AI coding agents, SSH and SFTP: real terminal panes, a Control Room for Claude Code, Codex and Gemini CLI, and a remote file browser in one native workspace.

This repository only hosts the Homebrew cask. For the app, guides, releases and support, go to the main repository: **[mxtermpro/Mxterm](https://github.com/mxtermpro/Mxterm)**.

## Install

```sh
brew install --cask mxtermpro/mxterm/mxterm-pro
```

The app is signed with an Apple Developer ID and notarized by Apple. MXterm Pro updates itself from inside the app.

Prefer a direct download, or on Windows or Linux? Use **[mxterm.net/download](https://mxterm.net/download)**.
